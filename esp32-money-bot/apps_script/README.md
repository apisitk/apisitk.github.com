# ตั้ง Google Sheet สำหรับ backup

บอทเป็นตัวจริง ชีตเป็น backup — ข้อมูลส่งขึ้นอัตโนมัติ ถ้าเน็ตหลุดจะรอในบอร์ดแล้วส่งทีหลัง

## ข้อมูลไปชีตไหน

| บัญชี | ไปที่ |
|---|---|
| ตั้งชีตแยกให้บัญชีไว้ (`/backup shop URL SECRET`) | ชีตนั้น |
| บัญชีส่วนตัว | ชีตของเจ้าของ (`/backup URL SECRET`) เท่านั้น |
| บัญชีแชร์ที่ไม่ได้ตั้งชีตแยก | ชีตของสมาชิกคนแรกที่ตั้งชีตไว้ |

พิมพ์ `/backup` ในบอทเพื่อดูว่าตอนนี้แต่ละบัญชีไปชีตไหน

**แนะนำ:** ทำ 2 ชีต
1. **ชีตส่วนตัวของคุณ** → `/backup URL SECRET` (ไม่ต้องแชร์ให้ใคร)
2. **ชีตร้าน** → `/backup shop URL SECRET` แล้วแชร์ชีตนี้ให้แฟนใน Google Drive

แฟนทำชีตส่วนตัวของตัวเองได้แบบเดียวกัน (ข้อ 1) — คุณจะไม่เห็นของเขา

## สร้างชีต (ทำทีละชีต)

1. สร้าง Google Sheet ใหม่ เช่น "ร้าน - backup"
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิม วางโค้ดจาก [`Code.gs`](Code.gs) แล้วกด 💾 Save
4. ⚙️ **Project Settings → Script Properties → Add script property**
   - Property: `SECRET`
   - Value: รหัสยาวๆ เดาไม่ได้ ไม่มีช่องว่าง เช่น `k8Qz2mX9vLp4wR7t`
5. **Deploy → New deployment** → ⚙️ **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy → Authorize access → (Advanced → Go to … unsafe — เป็นสคริปต์ของเราเอง)
   - คัดลอก **Web app URL** `https://script.google.com/macros/s/…/exec`
6. ส่งหาบอทใน Telegram:
   ```
   /backup shop https://script.google.com/macros/s/xxxx/exec k8Qz2mX9vLp4wR7t
   ```
   (ชีตส่วนตัว: ไม่ต้องใส่ `shop`)
   บอทจะทดสอบก่อน ถ้าผ่านจะส่งข้อมูลเดิมทั้งหมดขึ้นชีต — แล้วลบข้อความนั้นทิ้งได้

"Anyone" = ใครมี URL ก็ส่งมาได้ แต่ไม่มี SECRET จะถูกปฏิเสธ อย่าแชร์ URL + SECRET

## ในชีต

- 1 แท็บต่อ 1 บัญชี: `id | วันเวลา | ประเภท | จำนวน | หมวด | โน้ต | โดย | เลขอ้างอิง | สลิป`
- จำนวนติดลบ = รายจ่าย → `=SUM(D:D)` = คงเหลือ
- ส่งซ้ำไม่เกิดแถวซ้ำ (อัปเดตตาม id) รายการที่ลบหรือแก้ในบอทจะตามไปในชีต
- **อย่าแก้ตัวเลขในชีตเอง** — จะถูกทับเมื่อรายการนั้นถูกแก้ในบอท
  แต่เพิ่มแท็บสรุป/กราฟ/pivot เองได้ตามสบาย

## อ่านสลิปด้วย Typhoon

ใช้สคริปต์เดียวกันนี้ เพิ่ม Script Properties อีก 2 ตัวในชีตที่จะใช้อ่านสลิป:

| Property | ค่า |
|---|---|
| `TYPHOON_KEY` | API key จาก [playground.opentyphoon.ai](https://playground.opentyphoon.ai) → API Key |
| `BOT_TOKEN` | token บอทเดียวกับใน secrets.h (สคริปต์ใช้โหลดรูปจาก Telegram เอง) |
| `OCR_MODEL` | (ไม่ต้องใส่) ค่าเริ่ม `typhoon-ocr` — ใส่เมื่อ Typhoon เปลี่ยนชื่อโมเดล |
| `LLM_MODEL` | (ไม่ต้องใส่) ค่าเริ่ม `typhoon-v2.5-30b-a3b-instruct` |

ตอนกด Deploy ครั้งแรกหลังเพิ่มโค้ดอ่านสลิป Google จะขอสิทธิ์ "connect to an external service" เพิ่ม — กดอนุญาต

**ใช้สคริปต์ของใคร:** บอทลองสคริปต์ชีตส่วนตัวของคนที่ส่งสลิปก่อน (`/backup URL SECRET`)
ถ้าสคริปต์นั้นไม่มี `TYPHOON_KEY` จะใช้ตัวกลางที่ตั้งใน `secrets.h` (`SLIP_URL`, `SLIP_SECRET`)
→ ถ้าแฟนไม่อยากให้รูปสลิปส่วนตัวผ่าน Google ของคุณ ให้แฟนใส่ TYPHOON_KEY ในชีตตัวเอง

สคริปต์ไม่เก็บรูปหรือข้อความสลิปไว้ที่ไหน — โหลดรูป → ส่ง Typhoon → ตอบกลับบอท แล้วจบ
(แต่รูปผ่าน Google ของเจ้าของสคริปต์และ Typhoon/SCB 10X)

ข้อจำกัด Typhoon OCR: 20 ครั้ง/นาที — ส่งสลิปทีละใบ ไม่มีปัญหา

## รูปสลิปใน Google Drive

ชีตที่มี `BOT_TOKEN` ใน Script Properties จะเก็บรูปสลิปลง Drive ของเจ้าของชีตเอง
แล้วใส่ลิงก์ "ดูสลิป" ในคอลัมน์ **สลิป** (ไม่มี `BOT_TOKEN` = บันทึกแถวได้ตามปกติ แต่ไม่เก็บรูป)

```
My Drive / money-bot สลิป / ร้าน (shop) / 2026-10 / 20261018-1432_57_350.jpg
```

- เก็บ**หลังกด ✅** เท่านั้น (กดยกเลิก = ไม่มีไฟล์ค้าง) ลบรายการในบอท = ไฟล์ไปถังขยะ
- รูปไปอยู่ Drive ของ**ชีตที่บัญชีนั้น backup ไป** — สลิปร้านอยู่ Drive ชีตร้าน, สลิปส่วนตัวอยู่ Drive ของเจ้าของ
- ขนาด: ใช้รูปที่ Telegram ย่อไว้แล้ว เลือกใหญ่สุดที่ไม่เกิน **150KB** (ตั้งได้ที่ `SLIP_KEEP_MAX_BYTES` ใน config.h)
  ตอนอ่านด้วย Typhoon ยังใช้รูปใหญ่สุดให้อ่านตัวเล็กได้ชัด
  (ส่งสลิปเป็น "ไฟล์" แทน "รูป" จะได้ขนาดเต็ม เพราะ Telegram ไม่ย่อไฟล์)
- อัปโหลดทีละไม่เกิน 8 รูปต่อครั้ง ที่เหลือส่งรอบถัดไป (กันสคริปต์ทำงานนานเกิน)
- อยากให้แฟนดูรูปสลิปร้านได้ → แชร์โฟลเดอร์ `money-bot สลิป/ร้าน (shop)` หรือทั้งชีต+โฟลเดอร์ให้เขา
- ครั้งแรกหลังอัปเดตโค้ด Google จะขอสิทธิ์ Drive เพิ่ม ตอน Deploy → กดอนุญาต

## แก้โค้ดสคริปต์ทีหลัง

**Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
URL เดิมใช้ต่อได้ (ถ้ากด New deployment จะได้ URL ใหม่ ต้อง `/backup` ใหม่)

## มีปัญหา

| บอทตอบ | แก้ |
|---|---|
| ติดต่อไม่ได้ | URL ผิด หรือยังไม่ได้ Deploy เป็น Web app |
| ตอบกลับไม่ใช่ JSON | Who has access ไม่ใช่ **Anyone** |
| wrong secret | SECRET ใน Script Properties ไม่ตรงกับที่พิมพ์ |
| SECRET not set | ยังไม่ได้ทำข้อ 4 |
| ยังไม่ได้ตั้งตัวอ่านสลิป | ใส่ `TYPHOON_KEY` + `BOT_TOKEN` (ด้านบน) หรือ `SLIP_URL` ใน secrets.h |
| Typhoon … HTTP 401 | `TYPHOON_KEY` ผิด |
| Typhoon … HTTP 404 / model | ชื่อโมเดลเปลี่ยน → ตั้ง `OCR_MODEL` / `LLM_MODEL` ตามหน้า Models ของ Typhoon |
| อ่านสลิปช้า/หมดเวลา | Apps Script ตื่นช้าครั้งแรก ลองส่งใหม่ |
